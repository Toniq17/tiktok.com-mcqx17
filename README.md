## 🎯 Design Goals

The project focuses on a clean personal-brand presentation, strong typography, responsive layouts, lightweight front-end code and a polished user experience without unnecessary dependencies.

## 🚀 Run Locally

No build tools are required.

```bash
git clone https://github.com/Toniq17/tiktok.com-mcqx17.git
cd tiktok.com-mcqx17
```

Then open `index.html` in a browser, or serve the folder with any local static server.

## 📱 Responsive Support

The layout adapts across desktop, tablet and mobile breakpoints. Navigation, cards, grids, profile content and the contact area reorganize automatically for smaller screens.

## 🌙 Theme Support

Use the theme button in the navigation to switch between dark and light modes. The selected theme is saved locally in the browser so it remains available on the next visit.
